# เกม VR แยกคำศัพท์ภาษามลายู

เว็บแอปสำหรับให้นักเรียนยืนหน้ากล้อง จีบนิ้วจับบัตรคำศัพท์ แล้ววางลงกล่อง `Kata nama khas` หรือ `Kata nama am`

## วิธีเปิดใช้งาน

1. เปิดโฟลเดอร์นี้ด้วยเว็บเซิร์ฟเวอร์ในเครื่อง เช่น Live Server หรือคำสั่งเซิร์ฟเวอร์ของเครื่องที่มีอยู่
2. เข้าเว็บผ่าน `localhost` เพื่อให้เบราว์เซอร์อนุญาตใช้กล้อง
3. ถ้าตรวจจับมือไม่พร้อม ยังเล่นด้วยเมาส์หรือหน้าจอสัมผัสโดยลากบัตรได้

## ตั้งค่า Google Sheet

1. สร้าง Google Sheet ใหม่
2. ไปที่ Extensions > Apps Script
3. วางโค้ดจากไฟล์ `google-apps-script.gs`
4. Deploy เป็น Web app
5. ตั้งค่า Who has access เป็น Anyone with the link
6. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ในช่องลิงก์บันทึก Google Sheet ในเว็บแอป

## สิ่งที่ครูตั้งค่าได้

- เวลาเล่นต่อรอบ
- รายชื่อนักเรียนสำหรับสุ่มเรียก
- เพิ่ม ลบ และแก้ไขคำศัพท์
- เลือกประเภทคำศัพท์เป็น `Kata nama khas` หรือ `Kata nama am`
- ดูคะแนนย้อนหลังในแดชบอร์ดและส่งออก CSV

ข้อมูลตั้งค่าและคะแนนจะเก็บไว้ในเครื่องด้วย `localStorage` และพยายามส่งคะแนนไป Google Sheet เมื่อจบรอบ
